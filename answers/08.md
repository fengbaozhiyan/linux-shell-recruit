# Task08 Script Debug
## 问题解释
Shell 在变量展开时，如果写 （不带双引号）：
1. 执行**单词分割（word splitting）**：变量内容里的空白（空格、Tab、换行）会被当做分隔符，拆成多个独立参数；
2. 还会做**文件名通配符扩展（globbing）**，  等会匹配目录里的文件。

而 （双引号包裹变量展开）：
- 关闭单词分割，变量整体作为**单个参数**，内部空格保留；
- 也关闭 glob 通配扩展；
只保留  变量替换本身，适合文件名这类包含空格的字符串。

举个例子：
var="my file.txt"
-  → 展开成两个参数： 和 
-  → 展开成**一个完整参数**：

处理多文件传参时， 不带引号会分词； 保留每个原始参数，是脚本接收多个带空格参数的标准写法。
